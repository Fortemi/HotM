# HotM 2026.9.6

HotM 2026.9.6 isolates UI state by Fortemi endpoint and session context. API,
authentication, selected-memory, realtime and job-cache state no longer leaks
across server or view changes. Archive WebSocket and realtime subscribers retain
their owning context, and stale asynchronous results cannot replace a newer
selection.

Mobile note rows keep open, selection and lifecycle commands independently
operable at the 390px acceptance viewport. Navigation preserves the current
memory context while delete, restore and regeneration controls remain distinct.

The release also bounds CI coverage concurrency and updates the desktop Rustls
and AWS-LC lock for the current handshake-boundary security fix. Exact-source
Linux Tauri, UI, SDLC, OpenAPI-consumer and Mutsu desktop-matrix workflows passed
before release preparation.

The packaged Fortemi sidecar is pinned to immutable Fortemi `v2026.9.10` source
`306bae55a41eff7e4f8b8349304765322865e6cc` for Linux x86_64, Linux arm64,
macOS arm64 and macOS x86_64. Hosted Auth `v2026.9.0` admission and the named
claim contract `1.1.0` / `rust-node-jwt-v1` are unchanged. Knowledge Shard
claims remain profile-specific; this release does not establish Windows
qualification, complete backup, hosted tenant isolation, or suite parity. The
suite audit remains `NO-GO`.
