# HotM 2026.9.1

Opening Realtime Activity now preserves an existing Auth Required or incompatible
connection state. Previously, adding the drawer's subscriber could replace that
state with connecting even though no new stream was started. An explicit
connection close/reset can still start a new session.

This patch also corrects the browser fixtures used to verify realtime failures.
Hosted fixtures supply the accepted auth-contract metadata and assert that the
SSE endpoint was reached. Tests cover 401, 403, observable SSE 410, opaque legacy
WebSocket failure, and health-check unreachability, including the healthz
fallback. Desktop and mobile tests read the activity drawer because the compact
header badge is hidden on narrow screens.

Local candidate verification passed eight service/admission tests, typechecking,
and ten desktop/mobile browser cases. Release CI, artifact publication and
installed-image qualification are separate gates; #304 remains open until the
required evidence is recorded. Mocked transport tests do not establish a real
hosted authentication or tenant-isolation result.

The existing desktop sidecar pin is unchanged. This patch makes no new suite
parity, backup-completeness or portability claim.
