# HotM 2026.9.3

This correction makes the standalone UI container build self-contained. The
2026.9.2 image publisher failed because a unit-test fixture imported an authority
policy from the sibling agent-proxy directory, which is absent from the UI-only
build context. The fixture now derives the same exact authority release from
the UI's pinned compatibility receipt. The canonical verifier checks that
receipt against the immutable server source.

Hosted admission remains Fortemi Auth `v2026.9.0`, contract `1.1.0`, profile
`rust-node-jwt-v1`. The server owns custom PEM CA configuration for discovery
and JWKS; no browser certificate override is added. Live hosted authentication,
tenant isolation and realtime recovery require separate environment evidence.
The desktop sidecar pin remains unchanged. The signed 2026.9.2 tag is retained.
