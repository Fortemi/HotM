configurable CA bundle release. Hosted deployments must advertise contract
`1.1.0`, profile `rust-node-jwt-v1`, and this exact authority release. Older or
unknown release identities continue to fail closed; local anonymous use retains
its existing behavior.

The agent proxy consumes the exact producer release policy and unchanged JWT
conformance corpus. UI, proxy, and realtime browser fixtures use the same
release identity. The server owns PEM CA configuration for discovery and JWKS;
this release adds no browser certificate override.

The September auth receipt records pinned source identities and executed
consumer checks. Publication, installed-image qualification, and live hosted
reauthentication/realtime recovery remain separate gates. Fixture results do
not establish a live tenant-isolation outcome. The desktop sidecar pin is
unchanged.
