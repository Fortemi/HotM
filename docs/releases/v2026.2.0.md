# HotM v2026.2.0 Release Notes

**Release date:** 2026-02-19
**Channel:** beta

## Overview

HotM v2026.2.0 is the first formal release of the application as a standalone React SPA. The project has been fully migrated from its original Tauri desktop architecture to a browser-based single-page application that consumes the Fortemi API for all data operations.

This release delivers 17 feature views, a Sigma.js-powered knowledge graph, realtime event streaming, multi-archive support, and comprehensive search capabilities.

## Highlights

### Knowledge Graph Explorer

The graph explorer has been rebuilt on **Sigma.js** and **Graphology**, replacing the earlier canvas-based renderer. The new implementation features:

- **ForceAtlas2 layout** for natural clustering of related notes
- **Click-to-explore** navigation — click any node to focus it, double-click to open the note
- **Back/forward history** — browser-style navigation through explored nodes
- **Filter sidebar** — scope the visible graph by tags and extracted concepts
- **Node enrichment** — each node is annotated with its tags and NLP-extracted concepts from the per-note API
- **Sparse graph fallback** — graceful handling of archives with few or no links

### Realtime Event Bus

A new realtime event system keeps the UI synchronized with backend processing:

- **Dual transport** — WebSocket for low-latency updates, SSE as automatic fallback
- **Job queue monitoring** — watch NLP pipeline jobs progress in real time
- **Stalled detection** — automatic identification of stalled WebSocket connections
- **Debug inspector** — developer-facing view of the raw event stream

### Dashboard

The landing experience has been redesigned around a dashboard view:

- **Archive-scoped health summaries** — per-archive status at a glance
- **Notes workspace** — quick access to recent and starred notes
- **Job status** — active NLP pipeline jobs with pause/resume controls

### Multi-Archive Support

Full support for multiple Fortemi archives from a single HotM instance:

- Archive selector in the sidebar
- Scoped views — notes, jobs, health metrics are all filtered per archive
- Federated search across archives

### Search Modes

Three complementary search approaches:

- **Hybrid search** — combines PostgreSQL full-text search with pgvector semantic similarity, merged via Reciprocal Rank Fusion
- **Advanced search** — structured filters for metadata fields, tags, concepts, and date ranges
- **Memory search** — AI-assisted contextual retrieval powered by Fortemi's NLP pipeline

## Known Limitations

- **WebGL required** — the graph explorer requires a browser with WebGL support. A basic fallback is provided for environments without WebGL.
- **Fortemi API dependency** — all data operations require a running Fortemi API instance. There is no offline mode.
- **WebSocket configuration** — WebSocket transport can be disabled via `VITE_DISABLE_WEBSOCKET=true` if your deployment environment does not support persistent connections.
- **Mobile graph** — the graph explorer is functional but not optimized for touch interaction on small screens.

## Backend Compatibility

HotM v2026.2.0 requires **Fortemi API v1** (the `/api/v1/` endpoint namespace). Key API capabilities used:

- Notes CRUD with revision support
- Hybrid search (FTS + vector)
- Tag and concept extraction
- SSE and WebSocket event streams
- Archive management
- Attachment upload and retrieval
- Health and job monitoring endpoints

## Installation

### Development

```bash
git clone git@git.integrolabs.net:Fortemi/HotM.git
cd HotM/ui
npm install
npm run dev
```

### Docker

```bash
docker compose -f docker-compose.prod.yml up -d --build
```

See the [README](https://git.integrolabs.net/Fortemi/HotM/src/branch/main/README.md) for full configuration options.
