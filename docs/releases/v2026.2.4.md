# HotM v2026.2.4 Release Notes

**Release date:** 2026-02-22
**Channel:** alpha

## Overview

HotM v2026.2.4 is a feature-dense release focused on **media playback**, **rich attachments**, and **upload infrastructure**. The headline addition is a persistent pop-out media player that keeps video and audio playing across view navigation, eliminating the primary friction point for researchers reviewing recorded content while taking notes.

This release also delivers custom video controls with seek-preview thumbnails, resumable TUS uploads, a background upload queue, and a new unified search experience with concept/temporal/location filters.

## Highlights

### Persistent Pop-Out Media Player

The most requested feature for media-heavy workflows. When reviewing a lecture recording or reference audio, users can now pop the player out into a floating panel that persists across all view navigation.

**Architecture**: A `MediaPlayerProvider` context wraps at the `App.tsx` root level, outside `HallOfMind`'s view-switching tree. The `PersistentPlayerOverlay` renders as a sibling to the main content area, ensuring `currentView` changes never unmount the active media element.

```
App.tsx
├── MediaPlayerProvider          ← context holds session state
│   ├── HallOfMind              ← view switching happens here
│   │   └── (attachments use useMediaPlayerOptional to pop out)
│   └── PersistentPlayerOverlay ← renders outside view tree
│       └── MiniPlayer          ← floating, draggable, snaps to corners
```

**Three player modes**:

| Mode | Video Dimensions | Audio Dimensions | Controls |
|------|-----------------|------------------|----------|
| MINI | 280 x 210 px | 280 x 68 px | Play/pause, skip, mute, expand |
| EXPANDED | 480 x 398 px | 400 x 80 px | + minimize button |
| FULLSCREEN | Viewport | N/A | Full custom controls with thumbnail scrub bar |

**Key behaviors**:
- Drag the title bar to reposition; release near a corner to snap (120px threshold)
- Position persists to `localStorage` across sessions
- Double-click video to toggle fullscreen
- Fullscreen uses the container (not `<video>`), preserving custom controls and seek thumbnails
- Blob URL ownership transfers cleanly from the source component to the player context

**Keyboard shortcuts** (Alt modifier avoids editor conflicts):

| Shortcut | Action |
|----------|--------|
| Alt+P | Play / Pause |
| Alt+Left / Alt+Right | Skip back / forward 10s |
| Alt+M | Mute toggle |
| Alt+Shift+P | Dismiss player |
| Alt+Shift+E | Cycle MINI / EXPANDED |

**New files**: `ui/src/components/player/` — PlayerContext, MiniPlayer, PersistentPlayerOverlay, usePlayerPosition, usePlayerKeyboard

### Rich Media Previews

The attachment preview system has been completely rebuilt:

- **Streaming video** with native Range request support and blob fallback
- **Custom video controls** — scrub bar with sprite thumbnail previews on hover, play/pause, volume, closed captions toggle, fullscreen
- **Expert mode** — toggle real-time playback stats (bitrate, resolution, codec, buffer health)
- **3D model viewer** — model-viewer for compressed GLB files (replaced Three.js for smaller bundle)
- **SRT/subtitle support** — VTT/SRT transcript panel with interactive seek-to-segment
- **Error boundary** — unsupported media formats degrade gracefully without crashing the UI

### Upload Infrastructure

Two major additions to file upload capabilities:

- **TUS resumable uploads** — files >= 50 MB automatically use the tus protocol, enabling resume-after-disconnect for large media files
- **Background upload queue** — concurrent upload management with a global transfer status indicator. Users can navigate away from the upload view without interrupting transfers.

### Unified Search

The search experience has been consolidated and expanded:

- Renamed from "Advanced Search" to "Search" with a unified interface
- New filter types: concept scope, temporal range, and geographic location
- Preserved: full-text, tag, collection, and metadata filters

## Breaking Changes

None. This release is backwards-compatible with Fortemi API v1.

## Known Limitations

- **EXPANDED player** — functional but minimal styling enhancement over MINI; will be refined in a future release
- **DOCKED_BAR state** — defined in the state machine but falls back to MINI; implementation deferred
- **Native PiP** — element-level `requestPictureInPicture()` is not yet integrated; fullscreen via container is the current path
- **Mobile (<640px)** — floating player not optimized for small screens; a fixed notification bar is planned
- **"Return to note" navigation** — context wiring exists but is not yet connected to HallOfMind's view routing

## Backend Compatibility

HotM v2026.2.4 requires **Fortemi API v2026.2.10+** for full functionality:

- SSE v2 event format (overhauled in this release)
- Attachment streaming endpoints with Range support
- Thumbnail VTT sprite generation for seek preview
- TUS upload protocol endpoint
- Embedding configuration API
