# HotM 2026.5.4

**Release date:** 2026-05-09
**Type:** Patch — CI parity with the Fortemi docsite pipeline.

Drop-in replacement. No runtime changes to the desktop app, installer, or `.deb` — this release lights up the docsite CI/CD that was added on the Fortemi side in v2026.5.1, so HotM's `docs/` tree publishes to `docs.fortemi.io/hotm` on every push to `main`.

## Install

### Linux (one command)

```bash
curl -fsSL https://raw.githubusercontent.com/Fortemi/HotM/main/scripts/install.sh | bash
```

The installer is idempotent. Hosts already on 2026.5.3 will pick up the newer `.deb` on the next run; nothing about the install path changed in this release.

### Linux (.deb direct)

```bash
sudo apt-get install ./HotM_2026.5.4_amd64.deb
```

### macOS

```bash
hdiutil attach HotM_2026.5.4_aarch64.dmg
cp -R "/Volumes/HotM/HotM.app" /Applications/
hdiutil detach "/Volumes/HotM"
xattr -cr /Applications/HotM.app
```

### Docker UI image

```bash
docker pull ghcr.io/fortemi/hotm-ui:2026.5.4
```

## What changed

### Added

- **`.gitea/workflows/docsite-build.yml`** — PR validation. Runs the static docsite build against the `docs/` tree and fails the check on broken links, missing assets, or build errors. Mirrors the build job that lives in `Fortemi/.gitea/workflows/docsite-build.yml` so both repos have the same shape.
- **`.gitea/workflows/docsite-deploy.yml`** — push-to-main deploy. Builds the docsite and publishes to `docs.fortemi.io/hotm`. Triggered on `docs/**` and `.gitea/workflows/docsite-*.yml` changes only — code-only commits don't redeploy docs.
- **`docs/config.json`** — single source of truth for the docsite build (site name, base URL, navigation roots). Both workflows read from it; no more inline config drift between PR-validation and deploy.

### Changed

- **AIWG framework** refreshed to `2026.5.0-rc.21`. Affects `.aiwg/` tooling only — agents, skills, and rules that the SDLC framework deploys into the project. Doesn't change the desktop app, installer, or matric-api integration.

## Compatibility

Identical to v2026.5.3. PostgreSQL 18 still required (uuidv7 dependency in matric-api migrations). No host-adapter symbol changes, no API surface changes, no installer behavior changes.

## Verification

- Docsite build workflow validated against the current `docs/` tree — all links resolve, all referenced assets exist, build exits 0.
- Deploy workflow tested via dry-run; publishes to `docs.fortemi.io/hotm` on next push to `main` (which is this release).
- `act_runner exec -j quality-gate -W .gitea/workflows/ui-ci.yml` green.

Pairs with [Fortemi v2026.5.1](https://github.com/Fortemi/Fortemi/releases/tag/v2026.5.1) (the matching docsite CI release on the API side).
