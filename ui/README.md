HotM UI (Tauri + React)

Run (dev)
- Start the server: see `server/README.md`
- In this folder:

```bash
npm install
npm run dev
```

Build MSI
- Ensure Rust toolchain and Tauri prerequisites installed (Windows 11)
- In this folder:

```bash
npm run build
```

Global Hotkey
- Ctrl+Alt+H toggles the main window.
